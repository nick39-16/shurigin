# Weather Diary

**Автор:** Алексей Петров  

## Описание программы

Приложение "Weather Diary" предназначено для ведения дневника погоды. Пользователи могут вносить записи о погодных условиях (температуру, осадки, описания), просматривать существующие записи и применять фильтры по дате и минимальной температуре.
